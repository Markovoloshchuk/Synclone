# Synclone (Clone Memory Synchronizer)

> Високонавантажений веб-додатку для синхронізації та бекапу свідомості клонів (Data-Intensive Application).

---

## Вибір предметної області

* **Обрана предметна область:** **Синхронізатор пам'яті для клонів** (Варіант 6 — класичний приклад Data-Intensive Application / DIA).
* **Обґрунтування вибору:** 
  Ця предметна область обрана через складність та масштабність інженерних викликів, які вона ставить перед розробником. Сценарій із безперервним потоком бекапів свідомості мільйонів жителів вимагає проєктування системи з урахуванням високої інтенсивності запису (`high write throughput`), ефективного кешування, масштабування бази даних та забезпечення низької затримки (`low latency`). У межах цього курсу проєкт дозволить відпрацювати паттерни горизонтального масштабування, шардування та кешування даних.

---

## Швидкий запуск проєкту (Docker Compose)

Для локального розгортання проєкту разом із базою даних виконайте такі кроки:

1. Клонуйте репозиторій та переходьте в нього:
```bash
git clone <url-репозиторію>
cd Synclone

```


2. Запустіть сервіси за допомогою Docker Compose:
```bash
docker compose up --build

```


3. Після запуску:
* **API Документація (Swagger UI):** [http://localhost:8000/docs](http://localhost:8000/docs)
* **База даних PostgreSQL:** доступна на порті `5432`.
